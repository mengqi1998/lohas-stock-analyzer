樂活五線譜｜計算方式與欄位說明

本網站以歷史收盤價建立統計趨勢通道，透過線性迴歸與標準差， 觀察股價相對於自身歷史趨勢的位置。 所有訊號均以每日收盤價判斷。

一、五線譜計算方式

採用 Rolling Regression（滾動線性迴歸）。 每個交易日使用當天及之前最近 500 個交易日的收盤價， 獨立計算該日的趨勢線與標準差。

趨勢線：y = a × x + b
殘差：e = 實際收盤價 - 趨勢線預測值
標準差：σ = √(Σ(e - 平均殘差)² / 500)

其中 x 為迴歸區間內的交易日序號（0 至 499）， y 為該交易日收盤價；a 為迴歸斜率，b 為截距。 標準差採用母體標準差（ddof = 0）。

二、五條線的定義

線別 計算方式 意義
上上線 趨勢線 + 2σ 高於趨勢線兩個標準差的位置
上線 趨勢線 + 1σ 高於趨勢線一個標準差的位置
中線 線性迴歸趨勢線 歷史收盤價的統計趨勢
下線 趨勢線 - 1σ 低於趨勢線一個標準差的位置
下下線 趨勢線 - 2σ 低於趨勢線兩個標準差的位置

三、買進與賣出觀察訊號

🟢 買進觀察訊號（buy）

同時符合以下兩個條件：

  1. 前一交易日收盤價低於前一交易日的下下線。
  2. 當日收盤價回到當日下下線之上或相等。
前日收盤價 < 前日下下線
當日收盤價 ≥ 當日下下線

代表股價由下下線外側重新回到下下線範圍內。

🔴 賣出觀察訊號（sell）

同時符合以下兩個條件：

  1. 前一交易日收盤價高於前一交易日的上上線。
  2. 當日收盤價回到當日上上線之下或相等。
前日收盤價 > 前日上上線
當日收盤價 ≤ 當日上上線

代表股價由上上線外側重新回到上上線範圍內。

七、使用限制與注意事項

1. 訊號不等於買賣建議

五線譜是統計觀察工具，訊號不保證獲利，也不代表股價必然反轉。

2. 股價資料可能尚未還原權息

若使用未還原股價，除權息、減資、股票分割等事件可能影響長期趨勢與標準差。

3. 標準差不代表固定報酬機率

股價分布未必符合常態分布，因此 ±1σ、±2σ 是統計距離，不代表固定的漲跌機率。

4. 資料更新時間

網站使用 GitHub Actions 定期更新資料；瀏覽器同日快取可能顯示先前下載的版本，可使用強制更新取得網站最新資料。

5. 歷史訊號的解讀

每個交易日只使用當天及之前的資料計算五線，避免使用未來股價。不過這仍是統計訊號，實際交易還需考慮交易成本、滑價及其他風險。
