樂活五線譜｜計算方式與欄位說明

本網站以歷史收盤價建立統計趨勢通道，透過線性迴歸與標準差， 觀察股價相對於自身歷史趨勢的位置。 所有訊號均以每日收盤價判斷。

一、五線譜計算方式

採用 Rolling Regression（滾動線性迴歸）。 每個交易日使用當天及之前最近 500 個交易日的收盤價， 獨立計算該日的趨勢線與標準差。

趨勢線：y = a × x + b
殘差：e = 實際收盤價 - 趨勢線預測值
標準差：σ = √(Σ(e - 平均殘差)² / 500)

其中 x 為迴歸區間內的交易日序號（0 至 499）， y 為該交易日收盤價；a 為迴歸斜率，b 為截距。 標準差採用母體標準差（ddof = 0）。

二、五條線的定義

線別 計算方式 意義
明顯偏高線 趨勢線 + 2σ 高於趨勢線兩個標準差的位置
偏高線 趨勢線 + 1σ 高於趨勢線一個標準差的位置
長期趨勢線 線性迴歸趨勢線 歷史收盤價的統計趨勢
偏低線 趨勢線 - 1σ 低於趨勢線一個標準差的位置
明顯偏低線 趨勢線 - 2σ 低於趨勢線兩個標準差的位置

三、買進與賣出觀察訊號

🟢 買進觀察訊號（buy）

同時符合以下兩個條件：

  1. 前一交易日收盤價低於前一交易日的明顯偏低線。
  2. 當日收盤價回到當日明顯偏低線之上或相等。
前日收盤價 < 前日明顯偏低線
當日收盤價 ≥ 當日明顯偏低線

代表股價由明顯偏低線外側重新回到明顯偏低線範圍內。

🔴 賣出觀察訊號（sell）

同時符合以下兩個條件：

  1. 前一交易日收盤價高於前一交易日的明顯偏高線。
  2. 當日收盤價回到當日明顯偏高線之下或相等。
前日收盤價 > 前日明顯偏高線
當日收盤價 ≤ 當日明顯偏高線

代表股價由明顯偏高線外側重新回到明顯偏高線範圍內。

七、基本面與財務體質指標

指標白話說明判讀提醒
本益比目前股價是每股盈餘的幾倍。需與公司自身歷史、同產業比較，不能只看數字高低。
股價淨值比目前股價相對每股帳面淨值的倍數。產業資產結構不同，不宜跨產業直接比較。
毛利率營收扣除直接成本後，還剩多少比例。需觀察長期變化及產業特性。
營業利益率扣除營業費用後，核心本業留下的比例。可搭配營收一起觀察本業獲利是否改善。
稅後淨利率每一元營收最後留下多少稅後淨利。可能受業外損益及一次性項目影響。
負債比率總負債占總資產的比例。產業資本結構不同，不能用單一門檻判定好壞。
流動比率流動資產相對流動負債的倍數。僅作短期償債能力參考，仍需檢視資產品質。
營業活動現金流公司本業營運實際帶來的現金流入或流出。需看多期趨勢，不宜只用單季數字下結論。
近四季本期淨利合計最近四個財報季度的稅後淨利金額加總。這是金額，不是 EPS；本網站不直接相加各季 EPS，避免配股或分割造成股數基準不一致。

八、ETF 專用觀察

ETF 不套用個股本益比、股價淨值比或公司財報比率。應觀察每單位淨值（NAV）、市價相對淨值的折溢價、配息紀錄、投資標的與追蹤誤差。網站目前會顯示可取得的最近一次現金配息；NAV 與折溢價尚未自動串接，請以交易所或投信公告為準。

官方參考：證交所 ETF e 添富、公開資訊觀測站基金每日淨資產價值。

九、使用限制與注意事項

1. 訊號不等於買賣建議

五線譜是統計觀察工具，訊號不保證獲利，也不代表股價必然反轉。

2. 股價資料可能尚未還原權息

若使用未還原股價，除權息、減資、股票分割等事件可能影響長期趨勢與標準差。

3. 標準差不代表固定報酬機率

股價分布未必符合常態分布，因此 ±1σ、±2σ 是統計距離，不代表固定的漲跌機率。

4. 資料更新時間

網站使用 GitHub Actions 定期更新資料；瀏覽器同日快取可能顯示先前下載的版本，可使用強制更新取得網站最新資料。

5. 歷史訊號的解讀

每個交易日只使用當天及之前的資料計算五線，避免使用未來股價。不過這仍是統計訊號，實際交易還需考慮交易成本、滑價及其他風險。
